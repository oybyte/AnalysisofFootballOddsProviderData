# 市场与结算规则

## 胜平负

以主队视角记录 `home`、`draw`、`away`，不与让球结果混用。

## 亚洲让球

| 主队让球 | 主队结果 | 主队方向结算 |
|---:|---|---|
| 0 | 胜/平/负 | 赢/走/输 |
| 0.25 | 胜/平/负 | 赢/输一半/输 |
| 0.5 | 胜/平或负 | 赢/输 |
| 0.75 | 净胜2+/净胜1/其他 | 赢/赢一半/输 |
| 1.0 | 净胜2+/净胜1/其他 | 赢/走/输 |
| 1.25 | 净胜2+/净胜1/其他 | 赢/输一半/输 |
| 1.5 | 净胜2+/其他 | 赢/输 |

受让方向按相反结果结算。必须同时记录盘口、方向和对应快照时间。

## 大小球

整数线存在走盘，四分之一线拆分到相邻整数或半数线结算，半数线不存在走盘。总进球市场必须独立于让球市场评价。

## 校正说明

原始资料早期段落曾把平手盘平局和平半盘平局写成全输，后期汇总已改正。本规则已按后期一致口径修正。由于两个官方运营方规则页面在本次整理时未能稳定访问，当前可信度保持 `supported`，完成权威交叉验证前不得提升为 `established`。
