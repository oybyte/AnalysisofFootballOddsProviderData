# 赛前检查清单

- [ ] 已执行 `prepare-analysis` 并阅读全部必需规则。
- [ ] 基本面和盘口注明来源、采集时间及数据截止时间。
- [ ] 已列出缺失信息，不存在虚构伤停、首发或盘口。
- [ ] 理论盘口与实际盘口分开记录。
- [ ] 盘口按完整时间顺序记录，未把离散快照描述成连续走势。
- [ ] 已建立至少两个解释假设，并列出反向证据和失效条件。
- [ ] 主市场与主线方向匹配，不混合不同市场统计口径。
- [ ] 已给出 `pass` 或重新评估条件。
- [ ] 总进球和比分没有从让球方向线性推出。
- [ ] 置信度有明确依据并保留最大风险。
- [ ] 已列出采用和排除的规则 ID。
- [ ] 锁定前已通过全项目校验。
