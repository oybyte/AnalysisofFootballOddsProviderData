# 交叉盘、关联盘与同型盘

## 规则描述

同一时段或同一赛事中形态相似的盘口可以作为候选对照，但不能证明比赛间存在联合操盘或固定反向结果。

## 适用前提

比赛时间、联赛、盘口结构和数据阶段高度可比，并分别完成单场基本分析。

## 失效条件

为了匹配赛果强行绑定无关比赛，或把“一上一下”当成结算规律。

## 支持案例与反例

原始资料包含正反两类结果，尚未形成可统计的新格式样本。

## 当前结论

只能用于提示对照检查，不能进入核心证据层。
