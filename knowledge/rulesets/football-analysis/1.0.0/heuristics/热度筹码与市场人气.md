# 热度、筹码与市场人气

## 规则描述

球队名气、舆论题材和赔率门槛可以用于提出市场热度假设，但公开数据通常无法证明真实投注量。

## 适用前提

存在可核验的舆论、交易量或多机构同步变化，并已区分人气与真实实力。

## 失效条件

仅凭球队名气、单家赔率或主观感觉判断筹码方向。

## 支持案例与反例

尚未按新格式审核迁移，当前样本量为零。

## 当前结论

“大热必冷”和“反向大众即可获胜”均不成立，只能将热度作为风险修正项。
