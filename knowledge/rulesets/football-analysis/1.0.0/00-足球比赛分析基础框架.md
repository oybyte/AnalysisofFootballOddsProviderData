# 足球比赛分析基础框架

## 固定顺序

1. 记录带来源和采集时间的客观事实，明确数据截止时间。
2. 识别伤停、阵容、赛制、战意和盘口时序等缺失信息。
3. 根据阶段性基本面估算理论市场区间，再查看实际初盘偏差。
4. 按初盘、中盘、临场还原时间序列，以亚洲让球为主线，使用欧赔、大小球和凯利交叉验证。
5. 对关键变化同时建立正向和反向假设，分别列出证据、反证、成立条件和失效条件。
6. 先选择主市场，再给主线、次选、放弃条件和置信度；信息不足时输出 `pass`。
7. 总进球和比分只能在主线之后分层推演，不能由让球盘线性推出。
8. 锁定赛前内容，临场只追加，赛后按数据、概念、逻辑、权重、缺失信息和随机事件复盘。

## 优先级

客观事实高于解释，基本面和理论区间高于单次涨跌，完整时序高于截图片段，反证高于口号式经验，`pass` 高于强行结论。

## 边界

公开盘口无法证明机构内部资金流向。规则只提供可复核的分析流程，不承诺预测准确率，也不构成投注建议。
