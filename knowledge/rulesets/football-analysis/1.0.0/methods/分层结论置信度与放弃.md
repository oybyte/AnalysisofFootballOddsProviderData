# 分层结论、置信度与 pass

## 输出顺序

1. 选择唯一主市场。
2. 给出与主市场匹配的主线和次选。
3. 写明支持证据、最大反证和失效条件。
4. 写明触发重新评估或放弃的临场条件。
5. 给出 0 到 1 的置信度及依据。

不同市场不得合并成一个总准确率。置信度表示证据完整度与一致性，不表示确定概率。关键数据缺失、理论定位无法建立、市场持续冲突或无法形成可证伪假设时，主市场使用 `pass`，不填写置信度。
