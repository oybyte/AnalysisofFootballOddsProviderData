# 盘口时序与多市场交叉验证

## 记录方法

按采集时间记录机构、盘口档位、两侧水位、胜平负、大小球和数据来源。区分初盘、中盘和临场，不把不连续快照描述成完整走势。

## 判断顺序

1. 先看盘口是否跨档，再看同档水位。
2. 判断变化是持续、震荡还是临场突然反转。
3. 横向比较多家机构的一致与分歧。
4. 检查欧赔与让球是否支持相近的实力差结构。
5. 使用大小球判断进球环境，但不反推让球方向。
6. 凯利仅作辅助，不能单独决定方向。

信号持续矛盾、快照过少或临场剧烈往返时，应降低置信度或 `pass`。
