# 总进球与比分分层

让球描述净胜球差结构，大小球描述总进球环境，两者不能线性互推。

固定层级为：主市场方向、总进球区间、比分范围。大小球可以修正主线内部的比赛结构，但精确比分只作低优先级范围覆盖。不得因主流区间权重较高而把其他格局概率写成零。

赛后分别评价主线、总进球区间和比分范围，避免比分偶然命中掩盖主线逻辑错误。
