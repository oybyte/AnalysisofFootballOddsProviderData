# 基本面与阶段性定位

## 输入

近期正式比赛及对手强度、主客场表现、伤停停赛、预计首发、赛程和旅行、战意与赛制、战术风格、换帅与阶段状态、市场人气。

## 步骤

1. 区分长期纸面实力与当前阶段性表现。
2. 在同一联赛和同一时期内给球队分档，不跨联赛机械比较。
3. 单独修正主客场、阵容、体能、赛制和战意。
4. 分开记录真实实力判断与市场人气判断。
5. 对缺失信息列出可能影响，不用盘口反推不存在的伤停或战意。

## 输出

输出基础档位、阶段修正、主客场修正、阵容赛程修正、人气偏差和不确定性。档位是理论盘口的输入，不是比赛结论。
