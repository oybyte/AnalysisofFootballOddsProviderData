# 双向假设与证据权重

每个关键盘口变化至少建立两个可被证伪的解释，例如真实实力修正与市场风险调整。每个假设必须列出支持事实、反向事实、成立前提、失效条件和仍缺信息。

证据优先级为：可核验球队与赛制事实、理论与实际偏差、连续多机构时序、多市场共振、单机构单快照、未验证经验。重复描述同一数据不能当作多条独立证据。

如果两个假设都能解释现有数据且没有区分条件，结论应降低置信度或 `pass`，不能通过主观叙事强行选择。
