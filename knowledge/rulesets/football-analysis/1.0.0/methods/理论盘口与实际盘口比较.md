# 理论盘口与实际盘口比较

## 顺序

1. 在不引用后续盘路方向的前提下，根据阶段性定位估算合理让步或赔率区间。
2. 记录区间而非单一精确数值，并说明主要不确定项。
3. 与最早可核验实际初盘比较，标记为偏浅、合理或偏深。
4. 为偏差同时保留实力修正、信息差、市场人气和风控等解释。

## 失败条件

无法建立同联赛档位、缺少关键阵容或赛制信息、初盘时间无法确认时，不得输出强盘口深浅结论。

理论盘口不是客观真值，不能用最终赛果反向修改赛前估算。
