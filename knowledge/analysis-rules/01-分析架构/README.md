# 01-分析架构

本目录存放**分析预测比赛的底层架构**：整体框架、方法论、分析流程、维度划分。

它回答的是"怎么系统地分析一场比赛"，是所有具体规则的上位约束。
当具体规则与架构冲突时，以架构为优先（除非该规则明确标注更高优先级）。

## 本目录当前规则
（新增规则文件后，可在此列出文件名与一句话说明，便于速览）
