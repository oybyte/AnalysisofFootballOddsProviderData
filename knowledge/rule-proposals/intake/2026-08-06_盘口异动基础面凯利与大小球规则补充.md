# 盘口异动、基本面、凯利与大小球规则补充

## 规则 1：初始盘口离散度前置校验规则

- 适用场景：所有需要判定“机构集体调盘性质”的赛事场次。
- 触发条件：3 家及以上主流机构（澳彩、365、威廉、立博）初盘档位差大于等于 1 个完整盘口，即跨度大于等于 2 个小档位，例如半一 vs 球半。
- 判定逻辑：初始定价市场共识度不足，后续机构集体同向调盘优先定性为价值回归修正，而非机构主动示强或示弱；不得直接套用“集体降盘 = 真实示弱”“集体升盘 = 真实示强”的默认结论。
- 执行动作：调盘对应的权重调整幅度减半，原方向核心结论保留，不做优先级反转。

## 规则 2：跨联赛对阵战绩折价规则

- 适用场景：欧冠 / 欧联资格赛、洲际杯赛等不同联赛层级球队对阵的场次。
- 触发条件：将低级别联赛球队的内战连胜、连续零封等战绩，作为对阵高级别联赛球队的核心支撑逻辑时。
- 判定逻辑：小联赛或低级别联赛的内战战绩，面对更高层级联赛对手时，防守韧性、进攻效率需做折价处理；不得直接将内战战绩平移作为爆冷或赢盘的核心依据。
- 执行动作：弱势方的防守或进攻战绩权重下调一级，不得仅凭“连续零封”“连胜”判定其具备抗衡顶级联赛球队的能力。

## 规则 3：凯利同优先级区间判定规则

- 适用场景：所有胜平负凯利结构分析。
- 触发条件：6 家主流机构平均凯利的三项最大差值小于等于 0.05，作为主流高流动性联赛基准值。
- 判定逻辑：属于同优先级概率区间，机构对三项的赔付风险预期接近，不存在单一碾压级优势选项；强行拆分明确的第一或第二优先级属于过度解读。
- 执行动作：标注为“三项平权 / 双项平权”，优先推荐胜负组合，例如客队不败、主队不败，不做单一选项的绝对排序。
- 场景校准：低流动性小众联赛阈值放宽至小于等于 0.08；深盘（让球大于等于 2 球）场次仅对比平局与客胜的差值，不与主胜横向对比。

## 规则 4：临盘窄幅震荡无效规则

- 适用场景：赛前 2 小时内的临盘水位异动判定。
- 触发条件：盘口档位不变，水位在正负 0.08 区间内反复横跳，无明确单边走势，作为中浅盘基准值。
- 判定逻辑：属于多空资金正常博弈，机构核心态度未发生变化，不具备方向指示意义，属于市场噪音。
- 执行动作：维持赛前核心结论，不随短期水位波动频繁调仓，忽略窄幅震荡信号。
- 场景校准：深盘（一球及以上）阈值收窄至正负 0.05；低流动性联赛阈值放宽至正负 0.10。

## 规则 6：深盘临盘强示强判定规则

- 适用场景：所有主队让球大于等于 1.5 球的深盘场次，用于判定临盘水位异动的性质。
- 触发条件：主流赛事中，赛前 2 小时内 3 家及以上主流机构主队水位单边下行大于等于 0.15，且同时满足主胜赔率同步下行大于等于 0.05，平局、客胜赔率同步抬升。
- 判定逻辑：深盘场景下全平台主动收紧上盘赔付，属于机构真实提升主队赢盘预期，而非诱盘造热；不得直接套用“深盘默认下盘优先”的惯性结论。
- 执行动作：主队赢盘权重上调一级，上盘性价比从“偏低”修正为“中性偏可投”，净胜球预期同步上移一档。
- 场景校准：极深盘（让球大于等于 2 球）水位单边下行阈值收窄至大于等于 0.10；浅深盘（让球 0.75-1 球）阈值放宽至大于等于 0.18。

## 规则 8：双向极端控赔的进球锚定规则

- 适用场景：大小球盘口出现双向极端控赔的场次。
- 触发条件：两个相邻标准盘口，例如 2.5 球与 3.5 球，同时满足极端控赔标准（水位小于等于 0.65），且一端为大球极端低水、一端为小球极端低水。
- 判定逻辑：机构对进球数的共识高度集中在两个盘口的临界交集值，属于强区间锁定，而非双向夹击的模糊分歧；最高概率点为两个盘口的中间临界值。
- 执行动作：核心锚定临界值，例如 3 球，上下各 1 球为核心区间，两端概率平权，不偏向大球或小球单一方向；标注为“进球集中在临界值”。

## 规则 9：极端水位主动 / 被动区分规则

- 适用场景：所有出现极端水位（小于等于 0.65）的大小球场次。
- 触发条件：仅尾部机构（立博、Interwet 等）出现极端水位，头部 3 家主流机构（澳彩、365、威廉希尔）未同步进入极端区间，且头部机构盘口方向与极端水位方向相反。
- 判定逻辑：该极端水位为散户资金集中冲击导致的被动降赔，不属于机构主动控赔的真实态度，信号优先级大幅降低，反向诱盘概率显著上升。
- 执行动作：极端水位对应的方向权重调整幅度减半，核心结论跟随头部机构盘口方向，极端水位仅做风险提示，不得作为方向判定核心依据。

## 规则 10：大小球盘口分层校验规则

- 适用场景：所有大小球盘口异动判定，尤其低流动性联赛。
- 触发条件：头部 3 家主流机构与其他机构的盘口档位差大于等于 0.5 档，且方向完全相反。
- 判定逻辑：市场共识不足，头部机构的盘口调整对应更精准的临场信息与机构真实态度，优先级远高于尾部机构的水位波动；尾部机构的极端水位大概率是资金被动平衡的结果。
- 执行动作：大小球核心方向跟随头部机构盘口调整，核心区间同步移动一档，不套用尾部机构的极端控赔结论。
