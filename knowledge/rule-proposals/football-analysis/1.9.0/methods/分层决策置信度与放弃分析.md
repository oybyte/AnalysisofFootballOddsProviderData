# 分层决策、置信度与放弃分析

## 目的和适用范围

将是否参与、主市场、方向、次选、风险与置信度拆开，信息不足时明确 pass。

## 术语

- 置信度是证据质量和一致性的摘要，不是主观胜率
- pass 是有效结论
- 次选不能掩盖主线含糊

## 必需输入

- 数据完整性
- 规则与案例回执
- 双向假设结果
- 主市场结算定义
- 剩余未知项

## 数据质量要求

- 所有事实必须记录来源、采集时间和时区；不得用盘口反推不存在的伤停或资金事实。
- 原始盘口、水位和机构文字保留原字符串；无法确认口径时登记冲突。
- 历史案例只有 `prematch_verified` 且时间边界可证明时才可能进入统计。

## 逐步执行过程

1. 先决定是否可分析
2. 选择一个 primary_market
3. 选择与市场匹配的 primary_selection
4. 记录 secondary_selection
5. 按证据质量给置信度
6. 写出触发 pass 或推翻结论的条件

## 判断矩阵

| 条件 | 动作 | 边界 |
|---|---|---|
| 关键事实完整且主证据一致 | 可给中等以上置信度 | 仍保留随机事件 |
| 结论依赖单一经验 | 低置信度 | 不得写确定性 |
| 数据冲突或时间不明 | pass | 不计准确率 |

## 双向假设

- 假设 A：主证据足以形成可审计主线。
- 假设 B：剩余不确定性超过可接受范围，应放弃方向。
- 两个假设都必须填写支持证据、反证和锁定前可观察的区分条件。

## 区分触发条件

- 规则完整
- 主市场被回执覆盖
- 反例已处理
- 案例差异已说明

## 跨市场冲突优先级

1. 数据完整性高于方向偏好
2. 市场主线高于比分
3. 可复现证据高于样本内命中

## 失效和 Pass 条件

- 未知球队或赛事身份
- 结算盘口缺失
- 只剩相互冲突经验
- 开赛后才获得关键赛前信息

满足任一关键失效条件且无法在截止前补齐时，主市场应为 `pass`；不得用降低措辞强度代替 pass。

## 支持案例

- 多轮历史对话反复强调观望与风险等级

以上案例只说明规则的适用讨论，不自动计为合格证据。

## 反例

- 历史资料常在给出高风险后仍输出明确比分，1.1.0 禁止这种冲突

## 数据模式与置信度硬约束

- `complete`：关键市场口径完整，可按固定权重输出四层结论。
- `degraded`：缺少澳彩、三节点或某辅助维度；缺失维度计零，不重分配权重，置信度不得超过 `0.69`。
- `pass`：只记录原因，不输出置信度、市场方向、总进球区间或比分。
- 每个方向均给前二排序，不使用“必中”或无次选的极端表述。
