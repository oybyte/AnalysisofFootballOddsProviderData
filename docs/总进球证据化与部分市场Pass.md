# 总进球证据化与部分市场 Pass

`football-analysis@1.8.0` 是待审核的正式提案，不会修改活动 `1.5.0`。它将总进球与比分从“非 pass 必填”的全场输出中分离：胜平负和让球可继续完成降级分析，但总进球证据不足时必须单独标记 `pass`。

Contract 7 只读取赛前、无冲突、`exact` 的规范化观测。一个方向需要两个独立机构在相同机构/市场/盘口档位/赔率格式内形成合格时序；任何合格反向序列、跨档比较或缺少时间节点都会使总进球 `pass`。水位变化只记录价格事实，不归因于资金或机构意图。

总进球 `pass` 时不会生成区间、比分候选、锁定选择、自动结算命中或赛后统计分母。旧 Contract 4 回执与 `1.5.0` 的结果保持不变。
