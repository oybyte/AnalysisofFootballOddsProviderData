## 统一约束

- 用户文本无独立验证样本的声明保持 `experimental`。
- 单条实验规则最多移动一个名次，不得越过基础第一顺位。
- 只有同市场、同候选且数据血缘独立的两条规则同时支持，才进入锚点换位评估。
- 缺少节点、来源、格式或时间边界时记录 `insufficient_data`，不输出方向性校准。
